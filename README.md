# 王鑫烨｜理论物理、AI 与开放记录

Theoretical Physics · Correlated Topological Quantum Matter · Materials Calculations · AI for Science

我是一名保研至中国科学院物理研究所、选择理论物理方向硕博连读的学生，研究方向是**关联拓扑量子物态和材料计算**。

我对 AI 和 AI for Science 很感兴趣，平时也尤其关注科技与金融。我想了解新工具能做什么，也想弄清它们背后的原理，以及它们会怎样改变学习和科研。

我希望在互联网上留下一些属于自己的痕迹：自己的想法、做过的事，以及一路上的变化。

这里是我的个人档案。我会持续修改、补充，让它随着我的经历一起生长。

我也希望它成为与不同 AI 协作的共同起点。换一个工具时，我仍然可以带着自己的背景和偏好继续交流，并逐步积累这些资料。

## 我想在这里留下什么

一些真实的实践，一些还在形成的想法，还有那些让我改变看法的经历。随着积累，我会把作品、文章和学习记录陆续放进来。

我在之前的一次学习经验分享材料讨论中提过一句话：**工作要留痕。** 这个档案也是一次实践：让做过的事情留下记录，让有用的方法能够复用，让新的问题有地方接着想。

目前，这个档案刚刚开始。新的作品和记录会逐步加入。
